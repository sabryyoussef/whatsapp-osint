**واتساب بيكون** هي أداة مراقبة مفتوحة المصدر تعتمد على تقنية [OSINT](https://ar.wikipedia.org/wiki/%D8%A7%D8%B3%D8%AA%D8%AE%D8%A8%D8%A7%D8%B1%D8%A7%D8%AA_%D8%A7%D9%84%D9%85%D8%B5%D8%A7%D8%AF%D8%B1_%D8%A7%D9%84%D9%85%D9%81%D8%AA%D9%88%D8%AD%D8%A9) (استخبارات المصادر المفتوحة). تتيح لك تتبّع متى يتصل جهات اتصال محددة على واتساب وتسجيل كل جلسة اتصال في قاعدة بيانات SQLite محلية. يمكنها أيضًا تصدير البيانات إلى Excel وإنشاء لوحة تحليلات تفاعلية.

> **تنبيه**: هذه الأداة مخصصة لأغراض تعليمية وبحثية فقط. لا تستخدمها للمراقبة غير المشروعة أو أي أنشطة غير قانونية.

---

## 🎯 حالات الاستخدام

### 1. البحث الأمني والتوعية الشخصية
يمكن للأفراد الراغبين في فهم بياناتهم الشخصية المكشوفة على واتساب استخدام هذه الأداة للتحقق من المعلومات التي يمكن أن يراها الآخرون، مثل أوقات الاتصال وحالة "متصل الآن".

### 2. أبحاث الاستخبارات مفتوحة المصدر (OSINT)
تُستخدم أدوات OSINT من قِبل:
- **الباحثين الأمنيين** لدراسة أنماط سلوك المستخدمين وتقييم مخاطر الخصوصية.
- **مختبري الاختراق الأخلاقيين** لإثبات ما يمكن استخلاصه من بيانات واتساب العامة.
- **أكاديميي الجرائم الإلكترونية** لتحليل التسريبات السلوكية الرقمية.

### 3. الرقابة الأبوية (بموافقة صريحة)
يمكن للوالدين استخدام هذه الأداة لمراقبة أنماط استخدام أطفالهم القاصرين لواتساب بشكل شفاف وبعلم جميع الأطراف.

### 4. البحث الأكاديمي
تناسب الباحثين في علوم الحاسوب، وتحليل الشبكات الاجتماعية، وخصوصية البيانات الراغبين في تحليل سلوك المستخدمين الرقمي بشكل موضوعي.

### 5. التدريب على أدوات الأمن السيبراني
تُعدّ أداة تعليمية مثالية لتدريس مفاهيم التتبع الرقمي، وجمع البيانات العلنية، وتحليلها ضمن بيئات التعليم الأمني.

## ✨ الميزات الرئيسية

- **تثبيت سهل من PyPI**: `pip install whatsapp-osint`
- **مثبّت بأمر واحد**: يُهيّئ البيئة الافتراضية، ويثبّت الحزمة، ويتحقق من المتصفح تلقائيًا.
- **تتبّع في الخلفية (Headless)**: بعد المصادقة الأولى، تعمل الأداة بصمت دون إظهار نافذة المتصفح.
- **تاريخ الجلسات**: يُخزَّن كل سجل اتصال محليًا في قاعدة بيانات SQLite.
- **تصدير إلى Excel**: تحويل قاعدة البيانات إلى ملف `History_wp.xlsx`.
- **لوحة تحليلات متقدمة**: تقرير HTML تفاعلي يشمل خرائط حرارة، وجداول متصدرين، وفلترة لايف.
- **دعم متعدد اللغات**: يدعم الإنجليزية والعربية وغيرها لاكتشاف حالة "متصل".

## 🚀 التثبيت

### التثبيت من PyPI

```bash
python3 -m pip install whatsapp-osint
```

تُوفّر الحزمة أمرَين مكافئَين:

- `whatsapp-osint`
- `whatsapp-beacon`

### المثبّت السريع من GitHub

```bash
curl -fsSL https://raw.githubusercontent.com/jasperan/whatsapp-osint/master/install.sh | bash
```

ما يفعله المثبّت:
- يستنسخ المستودع أو يحدّثه داخل `./whatsapp-osint`
- ينشئ بيئة افتراضية `.venv`
- يثبّت الحزمة وأمر `whatsapp-beacon`
- يثبّت حزم النظام المفقودة (على Linux عبر `sudo`) بما في ذلك Chrome/Chromium
- يتحقق من توفّر متصفح قبل الانتهاء

## ▶️ تشغيل الأداة

```bash
whatsapp-beacon -u "اسم جهة الاتصال"
```

### التشغيل الأول

يتطلّب التشغيل الأول مصادقة واتساب ويب:

- **بدون وضع الخلفية (الافتراضي)**: امسح رمز QR مرة واحدة، وسيُعاد استخدام الجلسة المحفوظة في المرات القادمة.
- **وضع الخلفية (Headless)**: إذا لم تكن الجلسة مصادقًا عليها بعد، ستحفظ الأداة صورة لرمز QR في `qrcode.png`.

مثال:

```bash
whatsapp-beacon -u "محمد" --headless
```

---

## 📊 لوحة التحليلات المتقدمة

```bash
whatsapp-beacon --analytics
```

يُنشئ الأمر تقرير HTML في:

```text
analytics/index.html
```

تشمل اللوحة:
- مؤشرات الأداء الرئيسية (KPIs)
- جدول متصدرين لكل جهة اتصال
- أعمدة بيانية لوقت الاتصال اليومي
- خريطة حرارية (يوم الأسبوع / ساعة اليوم)
- توزيع مدة الجلسات
- جداول الجلسات الأخيرة والأطول
- فلتر لايف داخل الصفحة

## ⚙️ وسيطات سطر الأوامر

| الوسيط | الوصف | القيمة الافتراضية |
|--------|-------|-------------------|
| `-u`, `--username` | اسم جهة الاتصال المراد تتبّعها | مطلوب للتتبّع |
| `-l`, `--language` | رمز لغة واتساب ويب (`en`، `ar`، `fr`، إلخ) | `en` |
| `-e`, `--excel` | تصدير قاعدة البيانات إلى Excel | `False` |
| `--headless` | التشغيل بدون نافذة مرئية | `False` |
| `--chrome-driver-path` | المسار الصريح لـ chromedriver | اكتشاف تلقائي |
| `--chrome-binary-path` | المسار الصريح لـ Chrome أو Chromium | اكتشاف تلقائي |
| `--analytics` | إنشاء لوحة التحليلات والخروج | `False` |
| `--analytics-output` | مسار ملف تقرير HTML | `analytics/index.html` |
| `--config` | مسار ملف الإعداد المخصص | `config.yaml` |

---

## ⚙️ الإعداد

يمكنك حفظ الإعدادات الافتراضية في `config.yaml`:

```yaml
username: "اسم الهدف"
language: "ar"
headless: false
excel: false
browser: "chrome"
log_level: "INFO"
data_dir: "data"
chrome_binary_path: null
```

## 📦 مخرجات الأداة

- **السجلات**: `logs/whatsapp_beacon.log`

## 🔧 استكشاف الأخطاء وإصلاحها

### `cannot find Chrome binary`

```bash
whatsapp-beacon -u "اسم جهة الاتصال" --chrome-binary-path /المسار/الكامل/للمتصفح
```

### `Username is required`

وضع التتبّع يحتاج إلى اسم جهة الاتصال:

```bash
whatsapp-beacon -u "اسم جهة الاتصال"
```

وضع التحليلات لا يحتاج:

```bash
whatsapp-beacon --analytics
```
